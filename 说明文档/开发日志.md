## 2025-11-21（v2.0 升级）

- **Runtime Pipeline**：重写 `services.runtime_pipeline`，支持上传 CSV → GeoDataFrame 标准化 → 网格聚合 → Moran/Gi* → Trend → GeoJSON/CSV/HTML 一键串联，默认把成果输出到 `outputs/runtime`，自动生成带高德底图的 `risk_hotspots.html`。
  - 自动识别字段、生成批次 ID、记录时间范围、输出网格统计、热点 GeoJSON 与导出 CSV。
  - 通过 `bootstrap_runtime_assets()` 启动即加载示例数据，实现“开箱即用”。
- **浏览器端控制台**：`/` 路由升级为交互式面板，集成 CSV 上传、分析参数、热点列表、地图 iframe 与反馈表单，非开发人员也能直接体验 2.0 全流程。
- **API 联调成功**：`/api/upload`、`/api/analysis`、`/api/hotspots/geojson`、`/api/export`、`/api/feedback`、`/health` 全量重构，新增 POST/GET 双模式与错误兜底，前端/桌面端/HTML 三端均可直接消费。
- **可选依赖降级**：Moran、Gi*、Mann-Kendall 在缺失 libpysal/esda/pymannkendall 时自动降级为 numpy/pandas 算法，同时保留原有精确实现，保障无数据库/无 C 扩展环境下也能运行。
- **反馈存储兜底**：`feedback_service` 支持 MySQL + 本地 JSON 双写策略，新增 GET `/api/feedback` 查看反馈列表，方便演示闭环。
- **文档与版本**：README、平台介绍更新至 v2.0，补充理论—算法—功能映射、运行步骤与升级亮点，PyQt/Vue 页面无需改动即可读取新的后端成果。

## 2025-11-22（v3.0 升级）

- **结构化报告生成**：新增 `services.report_generator`，支持生成 Word/Excel/PDF 格式的风险分析报告，包含执行摘要、空间自相关分析、时空热点分析、趋势分析、应对建议等完整章节，可直接用于工作例会与警务简报。
- **三级预警推送系统**：新增 `services.alert_service`，实现红（加强的热点）、黄（新增热点）、蓝（持续的热点）三级预警自动分级，支持预警跟踪（已读/未读/已处置）、预警统计功能。
- **增强可视化服务**：新增 `services.visualization_service`，提供 LISA 聚类图、演化模式分布图、综合仪表盘、趋势折线图、时段分布柱状图等高级可视化。
- **策略模板管理**：增强 `services.recommendation`，支持策略模板保存与自定义，自动生成多部门协同建议。
- **API 扩展**：新增报告生成、预警推送、可视化相关的 API 接口，完善平台功能体系。

## 2025-11-22（v4.0 重大升级）

- **可视化集成与指令化转译**：
  - 新增 `services.interpretation_service`，将算法分析结果转化为一线民警可执行的明确工作指令，实现"算法输出 → 警务决策"的智能转译。
  - 核心指标看板升级：每个指标（网格数量、热点数量、Moran's I、趋势结果）配备解释图标和指令转译，悬停显示详细说明，实现"一眼清、一键达"的业务体验。
  - 图表窗口集成：采用可折叠标签页设计，集成综合仪表盘、趋势分析、时段分布三种图表，支持点击下钻、时间范围筛选、PNG/CSV导出。
  - 指令化转译面板：新增"警务决策指令"专属面板，包含指令摘要、详细指令、策略建议三个标签页，自动生成红/黄/蓝三级预警指令。

- **地图功能全面升级**：
  - 多地图类型一体化集成：三种专业地图（热点地图、LISA聚类图、演化模式分布图）在同一窗口无缝切换，通过图层管理实现平滑过渡。
  - 地图窗口交互增强：支持垂直方向高度调整（拖拽手柄）、全屏模式、比例尺控件，地图区域可动态调整大小。
  - 专业地图快照功能：新增 `services.map_snapshot_service`，支持一键快照、快照模板、元数据嵌入，提供简报/汇报/存档等多种导出模板。

- **用户上传与警务日志升级**：
  - 多媒体上传功能：升级 `routes.upload`，支持JPG、PNG、BMP、GIF等图片格式上传，自动生成缩略图，支持批量上传和即时预览。
  - 智能警务日志系统：新增 `services.log_export_service`，自动记录用户操作、分析任务、反馈记录，支持按时间范围、操作类型筛选导出为CSV格式，包含多媒体关联路径。

- **主页面模块化重构**：
  - 采用模块化HTML文件结构，将v4.0主页面拆分为7个独立模块文件（index_v4_01到index_v4_07），便于维护和扩展。
  - 实现动态模块加载机制，支持按需加载和独立开发。
  - 新增模板文件服务路由 `/templates/<filename>`，支持模块文件的独立访问。

- **API 扩展**：
  - 新增 `/api/interpretation/*` 路由：获取指令化转译、生成指令报告。
  - 新增 `/api/snapshots/*` 路由：创建地图快照、列出快照、下载快照。
  - 新增 `/api/logs/*` 路由：导出日志、获取日志统计。
  - 升级 `/api/upload/*` 路由：支持图片上传、列出已上传图片。

> v4.0版本实现了从"数据分析工具"到"警务决策支持系统"的跨越，将算法输出直接转化为可执行的工作指令，大幅提升一线民警的操作效率和决策支持能力。
