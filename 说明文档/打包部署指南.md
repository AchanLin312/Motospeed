## 方案一：PyInstaller打包（Windows）

### 适用场景
- ✅ Windows系统
- ✅ 单机部署
- ✅ 不需要Docker环境
- ✅ 需要独立exe文件

### 准备工作

1. **安装PyInstaller**
```bash
pip install pyinstaller
```

2. **确保所有依赖已安装**
```bash
pip install -r backend/requirements.txt
```

### 打包步骤

#### 方法1：使用自动化脚本（推荐）

```bash
python scripts/packaging/build_package.py
```

脚本会提示选择打包方式：
- 选项1：仅打包后端服务
- 选项2：仅打包桌面端
- 选项3：打包后端 + 桌面端
- 选项4：打包后端 + 桌面端 + 创建便携版

#### 方法2：手动打包

**打包后端服务：**
```bash
pyinstaller --name="数治骑迹-后端服务" \
    --add-data "backend/app/templates;app/templates" \
    --add-data "spatial_analysis;spatial_analysis" \
    --hidden-import=flask \
    --hidden-import=pandas \
    --hidden-import=geopandas \
    --console \
    backend/run.py
```

**打包桌面端：**
```bash
pyinstaller --name="数治骑迹-桌面端" \
    --add-data "ui/map_template.html;ui" \
    --add-data "backend/app/templates;app/templates" \
    --add-data "spatial_analysis;spatial_analysis" \
    --hidden-import=PyQt6 \
    --hidden-import=PyQt6.QtWebEngineWidgets \
    --windowed \
    ui/main_ui.py
```

### 打包结果

打包完成后，可执行文件位于 `dist/` 目录：
- `dist/数治骑迹-后端服务.exe` - 后端服务
- `dist/数治骑迹-桌面端.exe` - 桌面端应用

### 使用便携版

如果选择了"创建便携版"，会在项目根目录生成 `数治骑迹-便携版` 文件夹，包含：
- 可执行文件
- 启动脚本
- 使用说明

**使用方法：**
1. 将整个文件夹复制到目标电脑
2. 双击 `启动服务.bat` 启动后端
3. 访问 http://127.0.0.1:5000 或运行桌面端

### 注意事项

⚠️ **文件大小**：打包后的exe文件较大（约200-500MB），因为包含了Python解释器和所有依赖库。

⚠️ **首次运行**：首次运行可能需要几秒钟解压和初始化。

⚠️ **杀毒软件**：部分杀毒软件可能误报，需要添加信任。

⚠️ **路径问题**：确保 `outputs` 和 `uploads` 目录有写入权限。

## 方案二：Docker容器化（跨平台）

### 适用场景
- ✅ Windows/Linux/macOS
- ✅ 服务器部署
- ✅ 需要版本管理
- ✅ 多环境一致性

### 准备工作

1. **安装Docker**
   - Windows: 下载 [Docker Desktop](https://www.docker.com/products/docker-desktop)
   - Linux: `sudo apt-get install docker.io`
   - macOS: `brew install docker`

2. **验证Docker安装**
```bash
docker --version
docker-compose --version
```

### 部署步骤

#### 方法1：使用Docker Compose（推荐）

```bash
# 1. 构建并启动服务
docker-compose up -d

# 2. 查看服务状态
docker-compose ps

# 3. 查看日志
docker-compose logs -f

# 4. 停止服务
docker-compose down
```

#### 方法2：使用Docker命令

```bash
# 1. 构建镜像
docker build -t motospeed:latest .

# 2. 运行容器
docker run -d \
    --name 数治骑迹平台 \
    -p 5000:5000 \
    -v $(pwd)/outputs:/app/outputs \
    -v $(pwd)/uploads:/app/uploads \
    motospeed:latest

# 3. 查看日志
docker logs -f 数治骑迹平台

# 4. 停止容器
docker stop 数治骑迹平台
```

### 访问服务

启动后，在浏览器访问：
- **Web版**: http://localhost:5000
- **局域网访问**: http://[服务器IP]:5000

### 数据持久化

Docker容器中的数据会保存在挂载的卷中：
- `./outputs` - 分析结果、报告、图表
- `./uploads` - 上传的数据和图片

即使删除容器，数据也不会丢失。

### 更新服务

```bash
# 1. 停止旧容器
docker-compose down

# 2. 重新构建镜像（如果代码有更新）
docker-compose build

# 3. 启动新容器
docker-compose up -d
```

## 方案对比

| 特性 | PyInstaller | Docker |
|------|-------------|--------|
| **适用系统** | Windows | Windows/Linux/macOS |
| **文件大小** | 200-500MB | 镜像约1-2GB |
| **部署复杂度** | 简单（复制exe） | 中等（需要Docker） |
| **性能** | 原生性能 | 略低（容器开销） |
| **更新方式** | 替换exe文件 | 重新构建镜像 |
| **数据管理** | 本地文件 | 卷挂载 |
| **多实例** | 困难 | 容易（端口映射） |
| **资源占用** | 较低 | 较高（容器开销） |

### 选择建议

- **单机演示/测试**：使用 PyInstaller
- **服务器部署**：使用 Docker
- **跨平台需求**：使用 Docker
- **快速部署**：使用 PyInstaller
- **生产环境**：使用 Docker

## 常见问题

### PyInstaller相关问题

#### Q1: 打包后exe文件无法运行？

**解决方案：**
1. 检查是否有缺失的依赖库
2. 使用 `--debug=all` 参数查看详细错误信息
3. 确保所有数据文件（templates、static）都已包含

#### Q2: 打包后的文件太大？

**解决方案：**
1. 使用 `--onefile` 模式（单文件，但启动较慢）
2. 使用 `--onedir` 模式（目录模式，启动快但文件多）
3. 排除不需要的库：`--exclude-module=matplotlib.tests`

#### Q3: 运行时提示找不到模块？

**解决方案：**
在spec文件中添加 `hiddenimports`：
```python
hiddenimports=[
    '模块名',
]
```

### Docker相关问题

#### Q1: Docker构建失败？

**解决方案：**
1. 检查Dockerfile语法
2. 确保网络连接正常（需要下载依赖）
3. 查看构建日志：`docker build --no-cache -t motospeed .`

#### Q2: 容器无法访问？

**解决方案：**
1. 检查端口映射：`docker ps` 查看端口
2. 检查防火墙设置
3. 查看容器日志：`docker logs 数治骑迹平台`

#### Q3: 数据丢失？

**解决方案：**
1. 确保使用了卷挂载（`-v` 参数）
2. 检查挂载路径是否正确
3. 使用 `docker inspect` 查看卷信息

### 通用问题

#### Q1: 如何更新到新版本？

**PyInstaller方案：**
- 重新打包，替换旧exe文件

**Docker方案：**
```bash
docker-compose down
docker-compose build --no-cache
docker-compose up -d
```

#### Q2: 如何备份数据？

**PyInstaller方案：**
- 备份 `outputs` 和 `uploads` 目录

**Docker方案：**
```bash
# 备份卷数据
docker run --rm -v 数治骑迹平台_outputs:/data -v $(pwd):/backup \
    alpine tar czf /backup/outputs_backup.tar.gz /data
```

#### Q3: 性能优化建议？

1. **PyInstaller**：
   - 使用 `--onedir` 模式（启动更快）
   - 排除不需要的库

2. **Docker**：
   - 增加worker数量：`--workers 4`
   - 使用多阶段构建减小镜像大小
   - 配置资源限制

## 🔧 高级配置

### PyInstaller自定义图标

在spec文件中添加：
```python
exe = EXE(
    ...
    icon='path/to/icon.ico',  # Windows图标文件
)
```

### Docker生产环境配置

修改 `docker-compose.yml`：
```yaml
services:
  motospeed:
    environment:
      - FLASK_ENV=production
      - WORKERS=4  # 增加worker数量
    deploy:
      resources:
        limits:
          cpus: '2'
          memory: 4G
```

### 添加HTTPS支持

使用Nginx反向代理：
```nginx
server {
    listen 443 ssl;
    server_name your-domain.com;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    location / {
        proxy_pass http://localhost:5000;
    }
}
```
