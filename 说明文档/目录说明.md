# 目录说明

本次整理遵循两个原则：

1. 不动核心业务目录：`backend/`、`frontend/`、`ui/`、`spatial_analysis/`、`outputs/`、`uploads/`
2. 将散落在根目录的辅助资料收拢到对应分区，减少视觉噪音

当前建议按下面方式理解项目：

- `数治骑迹-便携版/`：优先使用的启动入口
  - `启动服务.bat`：启动后端服务
  - `启动桌面端.bat`：优先尝试源码桌面端，失败时回退到 exe
- `说明文档/`：论文、讲稿、变更记录、维护说明、流程图
  - `项目维护/`：部署说明、打包问题记录、文件处理清单
  - `历史归档/`：从根目录归档下来的旧资料
- `scripts/`
  - `packaging/`：打包与清理脚本、spec 文件
  - `docs/`：Markdown/Word 辅助处理脚本
  - `generate_hotspot_map.py`：地图生成脚本
- `.vendor/`：本地补充依赖目录，用于便携启动兜底

如需重新打包，建议使用：

```bash
python scripts/packaging/build_package.py
```

如需清理打包缓存，建议使用：

```bash
python scripts/packaging/clean_build.py
```
