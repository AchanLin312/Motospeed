数治骑迹平台技术特点总结
========================================

一、空间统计算法实现
----------------------------------------

1.1 全局与局部Moran's I空间自相关分析

系统实现了完整的Moran's I空间自相关分析算法，支持全局和局部（LISA）两种模式。

技术亮点：
- 双实现机制：优先使用libpysal/esda库的高精度实现，缺失时自动降级为numpy/pandas纯Python实现，确保在任何环境下都能运行
- KNN权重矩阵：采用K近邻（k=5）构建空间权重矩阵，支持行标准化（transform="R"）
- 降级算法实现：当依赖缺失时，使用基于距离阈值的权重矩阵（radius=0.01度）作为fallback

代码示例（spatial_analysis/moran_analysis.py）：
```python
def _ensure_weights(gdf: gpd.GeoDataFrame, k: int = 5):
    if HAS_PYSAL:
        w = KNN.from_dataframe(gdf, k=k)
        w.transform = "R"  # 行标准化
        return w
    return _fallback_weight_matrix(gdf)  # 降级实现
```

1.2 Getis-Ord Gi*热点识别

实现了Getis-Ord Gi*统计量计算，用于识别空间热点和冷点区域。

技术亮点：
- 自动风险分级：根据Z值自动划分为高风险（Z≥2.58）、中风险（1.96≤Z<2.58）、低风险（1.65≤Z<1.96）
- 降级策略：缺失esda时使用z-score标准化作为近似
- 热点多边形生成：基于MultiPoint的凸包和缓冲区算法生成热点区域多边形

代码示例（spatial_analysis/hotspot_analysis.py）：
```python
def _classify_risk(z_score: float) -> str:
    if z_score >= 2.58: return "high"
    if z_score >= 1.96: return "medium"
    if z_score >= 1.65: return "low"
    return "insignificant"
```

1.3 Mann-Kendall趋势检验

实现了Mann-Kendall非参数趋势检验，用于识别超速行为的时间演化趋势。

技术亮点：
- 支持pymannkendall库的精确实现
- 降级方案：使用差分趋势近似方法
- 输出趋势类型：increasing（上升）、decreasing（下降）、no trend（无趋势）


二、数据处理与清洗流程
----------------------------------------

2.1 智能字段映射与数据标准化

系统实现了灵活的字段识别机制，支持多种数据格式的自动适配。

技术亮点：
- 多候选字段匹配：通过_pick_column函数支持不区分大小写的字段名匹配
- 自动类型转换：时间戳、经纬度、速度等字段自动转换为标准格式
- 容错处理：缺失字段时自动生成默认值或抛出明确错误

代码示例（backend/app/services/runtime_pipeline.py）：
```python
def _pick_column(df: pd.DataFrame, *candidates: str, default=None):
    """根据候选名称（不区分大小写）选择列"""
    lowered = {col.lower(): col for col in df.columns}
    for name in candidates:
        key = name.lower()
        if key in lowered:
            return df[lowered[key]]
    if default is not None:
        return default
    raise KeyError(f"缺少必要字段：{'/'.join(candidates)}")
```

2.2 轨迹数据清洗算法

严格按照论文2.2.1节实现数据清洗流程，包括：
- 漂移点剔除：基于速度上限（40km/h）和时间间隔的距离检查
- 缺失点截断：时间间隔>20秒时截断轨迹链
- 轨迹子链过滤：保留连续点数≥5的轨迹子链

2.3 地图匹配（IVMM改进）

基于IVMM算法进行改进，适配共享电动自行车特征：
- 删除高速公路、快速路等不可通行道路
- 将道路拓扑关系改为无向图，支持逆行行为
- 增加偏移量字段，提取道路红线范围内的轨迹链


三、系统架构设计
----------------------------------------

3.1 Runtime Pipeline轻量化架构

核心创新：实现了完全脱离数据库的轻量化运行时数据管线。

技术亮点：
- 文件存储：所有中间结果和最终成果存储在outputs/runtime目录
- 一键分析：从CSV上传到热点GeoJSON/HTML生成的全流程自动化
- 批次管理：每次上传自动生成批次ID，支持多批次数据管理

架构优势：
- 零数据库依赖：可在无PostGIS/MySQL环境下完整运行
- 快速部署：无需配置数据库连接，开箱即用
- 数据可追溯：所有中间文件保留，便于调试和复现

代码示例（backend/app/services/runtime_pipeline.py）：
```python
RUNTIME_DIR = ROOT_DIR / "outputs" / "runtime"
```

3.2 模块化服务层设计

采用清晰的分层架构，实现高内聚、低耦合：

系统实现了多层次的容错机制：

四、指令化转译技术
----------------------------------------

4.1 算法结果到警务指令的智能转译

创新点：将复杂的空间统计结果转化为一线民警可直接执行的工作指令。

技术实现：
- 规则引擎：基于Moran's I值、热点数量、趋势类型等指标，自动生成分级指令
- 三级预警：红色（紧急）、黄色（预警）、蓝色（常态）
- 策略建议：结合热点类型（振荡/新增/逐渐减少）生成差异化应对策略

代码示例（backend/app/services/interpretation_service.py）：
```python
if moran_i > 0.3:
    pattern = "高度集聚"
    strategy = "集中布控"
    instruction = f"空间自相关指数为 {moran_i:.3f}，表明超速行为呈{pattern}模式，建议采取{strategy}策略"
elif moran_i > -0.1:
    pattern = "随机分布"
    strategy = "全域巡逻"
    instruction = f"空间自相关指数为 {moran_i:.3f}，表明超速行为呈{pattern}模式，建议采取{strategy}策略"
```

4.2 指标解释与业务映射
