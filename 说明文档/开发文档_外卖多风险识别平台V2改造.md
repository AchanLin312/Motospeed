## 1. 改造概述

V1 平台（数治骑迹 v6.0）以机动车犯罪热点分析为主，仅覆盖单一"超速"维度。本次按甲方手册升级为 **外卖电动车多风险识别与治理辅助平台**，新增：

1. **三类风险行为识别**：超速（20 km/h + 连续 10 s）、疑似逆行（单向路方向差 / 双向路叉积）、急变速（运动样本 85%/15% 分位阈值）；
2. **IVMM 地图匹配**：候选 + 投票 + 路径连续性的完整 HMM 匹配（非最近路投影），无向拓扑适配电动车，同时保留道路方向供逆行判定；
3. **熵权 + TOPSIS 综合评分**：三项事件率 → 客观权重（和为 1）→ 综合风险指数 CRI 0–100；
4. **四套热点图层**：综合 CRI / 超速率 / 疑似逆行率 / 急变速率各自独立 Gi\* 热点，无显著时兜底 top8 高风险网格；
5. **AI 治理建议**：15 条知识库规则（KB-G01…KB-F01）+ LLM 预留接口（OpenAI 兼容，环境变量密钥）+ 规则兜底；
6. **API v2 与双模式**：`/api/v2` 19 个接口，业务/管理模式分离，管理模式接口 `X-Admin-Token` 鉴权；
7. **前端双端**：Web 单页 `index_v5.html`（Leaflet 双底图 + 四图层切换 + AI 建议面板）+ PyQt6 桌面端新增"V2 平台"页签（QWebEngineView 内嵌）。

改造原则（D2）：**新逻辑全部放新文件**（`*_service.py` v2、`api_v2/`），V1 文件尽量不动，保证 AC28 原功能兼容。

## 4. 数据接入与勘验（M0）

### 4.1 源数据字段映射（15 列 → 标准轨迹）

| 源列 | 含义 | 处理 |
|---|---|---|
| TS / POSITIONTIME | 时间戳 | 解析为 UTC-aware datetime；确认数据范围 **2024-06-05 07:00–08:59**（AC02） |
| BICYCLEID / NEW_BICYCLEID | 车辆编号 | 优先 NEW_BICYCLEID，缺失回退 BICYCLEID |
| COMPANYID | 企业编号 | 保留 |
| BICYCLE_LNG / BICYCLE_LAT | 经纬度 | **分析坐标**（M0 勘验：与路网贴合距离中位约 7.5 m） |
| X_position / Y_position | 备用坐标 | 与路网偏差约 500 m，判定为坐标系之别，**不用于分析**（D5 勘验结论落定） |
| Speed | 瞬时速度 | **单位 m/s**，换算 km/h ×3.6；与 `Distance/Time_consuming` 重算互验一致（AC03） |
| LOCKSTATUS / LOCKID / TID | 锁状态/订单 | 保留语义用于清洗规则 |

### 4.2 数据校验规则（DV01–DV08）

`data_import.py` 导入时强制校验：必填列缺失阻断、时间乱序/超界隔离、坐标超 bbox 隔离、Speed 非正值隔离、异常行超比例（>5%）整批阻断。被隔离行写入 `isolated_rows.csv` 可追溯，原始行数/保留行数/隔离行数记入 `meta.json`（对账表数据源）。

### 4.3 停止加载旧数据（AC01）

`bootstrap_runtime_assets()` 不再自动加载 V1 的 `data.csv` / `test_data.csv`；首页默认识别最新 V2 批次或提示选择批次。

## 5. 路网服务与 IVMM 地图匹配（M1）

### 5.1 路网导入（AC05/AC07）

`road_network_service.py`：shapefile 成套上传（zip 或多文件）→ 按 **亦庄 bbox (116.455, 39.705)–(116.592, 39.828)** 裁剪 → WGS84 → **UTM 50N (EPSG:32650)** → networkx 构建**无向图**（电动车逆行判定需要无向拓扑参与匹配），**每条边保留 `oneway`（B/F/T）、`fclass`、`name` 等属性**供逆行判定使用。记录数、坐标系、裁剪范围、版本号写入 `meta.json`。

oneway 语义（D8 实证落定）：`F` = 顺向单向、`T` = 逆向单向、`B` = 双向；无 oneway 属性按双向处理。

### 5.2 IVMM 算法（AC06）

`map_match_service.py` 实现完整 IVMM（候选 → 发射概率 → 转移概率 → Viterbi 全局最优），**非单纯最近路投影**：

| 参数 | 值 | 说明 |
|---|---|---|
| IVMM_ALPHA | 5 | 每点最大候选路段数 |
| IVMM_R | 100 m | 候选查询半径 |
| IVMM_BETA_FAST | 10 | 相邻点间隔众数 < 10 s（贴合实测 GPS σ≈7.5 m） |
| IVMM_BETA_SLOW | 8 | 间隔 ≥ 10 s（稀疏链发射项收紧）W |
| IVMM_GL_THRESHOLD | 10 | 转移概率归一化参数 |
| IVMM_FAR_M | 45 m | 最近候选超此距离视为不可匹配（园区内部/漂移点） |

输出点级 8 字段：`matched_road_id / road_class / road_length_m / oneway / offset_m / matched_lon / matched_lat / match_score`，并按道路等级偏移上限表校验。匹配率与参数快照写入 `match_meta.json`。

## 6. 三类行为识别（M2，rule_version = `v2.0-20240605`）

`behavior_service.py`，参数集中在 `services/v2/__init__.py`：

| 行为 | 规则 | 对应 AC |
|---|---|---|
| 超速 | 速度 > 20 km/h（m/s×3.6 换算）**且连续 ≥10 s**、≥2 点构成事件；边界 19.99/20.00/20.01 与 9.9/10/10.1 s 用例通过 | AC08 |
| 疑似逆行（单向路） | 行驶方向角差 ∈ [135°, 225°]（容差 α_d=45°）；子链 >50% 逆行点判"疑似逆行事件"；边界 134.9/135/180/225/225.1°、49.9/50/50.1% 用例通过 | AC09 |
| 疑似逆行（双向路） | 叉积几何判定（道路单位向量 × 位移向量左侧为逆行），正反方向样例通过 | AC10 |
| 急变速 | 仅**运动状态**样本参与；阈值取运动样本加速度 **85%/15% 分位**；采样间隔 >6 s 不可判定**且不插值**；排除停车急启动；连续风险点合并为一次事件（点数 ≠ 事件数） | AC11–AC13 |

输出两级结果：`matched_points.csv`（点级，含 quality_flag）与 `events.csv`（事件级：batch_id/segment_id/behavior_type/start_end_time/事件点数/rule_version/quality_flag）。无法人工确认的逆行保留"疑似"表述。

## 7. 网格聚合与评分（M3）

### 7.1 网格聚合（AC14/AC15）

`grid_aggregation_service.py`：**默认 250 m** 网格（管理员可改 100/500 m，生成新分析版本），UTM 米制。**骑行暴露量** = 有效里程按轨迹路径与网格的**相交长度分配**（跨网格不重复计），三类事件率单位 **次/100 km**。网格级 quality_flag 标记有效里程/轨迹数不足（KB-D01）。

**质量门控（幽灵热点修复）**：quality_flag 判定——暴露 ≥1 km 且行驶段 ≥5 为 `valid`；有暴露或有事件但未达标为 `low_exposure`；其余 `insufficient_data`。**三类事件率仅在 valid 网格上计算**，低暴露网格率值留空（语义为"无数据"而非 0）——否则微小分母会制造统计噪声（真实案例：5 m 暴露 3 起逆行 → 62,516 次/100 km）。事件计数始终保留原始事实。

### 7.2 熵权 + TOPSIS（AC16/AC17）

`scoring_service.py`：**仅 quality_flag=valid 的网格参与**熵权定权与 TOPSIS 评分（`weights.json` 记录 `n_valid_grids/n_grids_total`）；低暴露网格视为无数据（CRI 与三类危险指数留空，不记 0），既不参与定权也不作为理想解参照。三项事件率 → 熵权法客观权重（**和恒为 1**；指标无差异时权重为 0）；同分析版本缓存 `weights.json` 不重算，新版本重算。TOPSIS 贴近度映射为 **CRI 0–100** 及三类危险指数 0–100，结果可追溯到事件率与权重。急变速样本不足时综合指数标记不可用（不记 0 分），`rapid_available=false`。

## 8. 热点分析 v2（M4）

### 8.1 四套热点图层（AC18）

`hotspot_service.py` 复用 V1 `spatial_analysis/hotspot_analysis.py` 的 `getis_ord_indicator`（KNN k=5，UTM 50N），对 **comprehensive（CRI）/ overspeed / reverse / rapid** 四个指标分别做 Gi\*。Z 分级：≥2.58 极高、≥1.96 高、≥1.65 较高。各图层 GeoJSON 独立缓存于 `hotspots/<layer>.geojson`，前端切换直接读缓存。

**质量门控**：非 valid 网格**不参与 Gi\***——既不产出热点多边形，也**不作为 KNN 邻居**进入其他网格的邻域总和。若不过滤，KNN 会跨越数据空洞把孤立空格与远处异常格拼成"邻域"，把 0 值格子推成热点（真实案例：G0034_0033 自身全 0 却 Z=5.36，由邻域内低暴露噪声网格抬升）。Moran/LISA 同样仅作用于 valid 网格。前端网格详情对非 valid 网格显示"无数据（低暴露）"提示，事件计数照常展示。

### 8.2 兜底网格（AC19）

某图层无显著热点（全部 Z < 1.65）时，返回风险值 top8 网格并标注 `selection_type=top_risk_fallback`，前端明确提示"未达到 Gi\* 显著性"。

### 8.3 单日限制与对账（AC25）

单日 2 小时数据下，趋势/演化/动态预警模块**保留但显示"数据不足"**，不生成虚假结论。`summary.json` 汇总对账字段：原始行数（rows_total）、清洗后行数（rows_kept）、隔离行数、匹配成功点数与匹配率、有效里程、三类点数/事件数（event_counts）、有效网格数（grid_count）、三项权重（scoring.weights）、各图层热点数与兜底数（hotspots）、质量分布（quality_flag_counts）——前端、报告、导出均以此为准。

## 9. AI 治理建议（M6）

### 9.1 架构（AC21–AC24）

```
POST /advice/generate（grid_id + risk_layer）
   → advice_service 生成建议（六部分）
        ① 优先读取缓存 advice/<grid_id>.json（相同缓存键不再调用 LLM，AC21）
        ② 知识库检索：15 条规则按网格指标触发，产出 basis_ids
        ③ LLM 增强（预留）：LLM_API_BASE/KEY/MODEL 齐备时调用 OpenAI 兼容接口
           - 外发白名单：仅聚合指标（CRI/指数/事件率/暴露量/道路等级占比），无车辆编号/设备编号/逐点轨迹（AC22）
           - 45 s 超时（LLM_TIMEOUT_S）、断网/超时/无额度自动降级规则模板，页面不崩溃（AC24）
        ④ 未配置 LLM 时直接用知识库规则模板兜底
   → 建议结构：risk_summary / field_actions / road_environment_checks /
              platform_coordination / education_actions / verification
```

### 9.2 知识库规则（15 条，`kb_data/KB-1.0.json`）

| 编号 | 触发条件（要点） | 建议部分 |
|---|---|---|
| KB-G01 | 综合指数高且 Gi\* 显著（gi_z≥1.65 且 cri≥P75） | field_actions |
| KB-G02 | 三类中至少两类指数较高（≥2 个达 P75） | field_actions |
| KB-S01/KS-S02 | 超速主导 / 超频高频 | field_actions |
| KB-R01/KR02 | 单向路（oneway F/T 占比≥0.5）/ 双向路逆行占比高 | field_actions / road_environment |
| KB-A01/A02/A03 | 急加速≥1.5×减速 / 减速≥1.5×加速 / 均高 | field_actions / road_environment |
| KB-E01/E02 | 车辆≥3 且事件≥5 / 任一指数达 P90 | platform_coordination / education |
| KB-D01/D02/Q01 | 里程轨迹不足 / 兜底网格 / 急变速可判定率低 | verification |
| KB-F01 | 已形成治理建议（恒触发） | verification |

`GET /advice/<grid_id>/basis` 返回依据明细（规则编号/来源/适用限制），前端**默认隐藏、点击按钮显示**（AC23）。
