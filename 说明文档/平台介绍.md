# 数治骑迹介绍

## 1. 理论与数据基础

- **治安治理视角**：平台源于《论文.md》提出的“新质生产力赋能公安交通治理现代化”命题，聚焦共享电动自行车高速扩张带来的高频违法与事故风险，响应国家“公共安全治理模式向事前预防转型”的战略要求。
- **知识体系**：以“数据-行为-风险-预警”四位一体理论为主脉，结合时空立方体、Moran’s I、自组织热点、Mann-Kendall 趋势检验等模型，形成可解释的风险识别与演化分析框架。
- **数据特征**：底层数据与论文完全一致：371,995 条订单、清洗后 324,555 条有效订单、172,294 条轨迹链、130,562 次超速事件，字段包含订单元信息、轨迹点经纬度、速度、开/关锁状态等，保证研究与实战一致性。

## 2. 功能模块

1. **数据上传与入库**
   - pandas + geopandas + pyproj 按论文 2.2 规范解析 CSV、校验时间戳与 WGS-84 坐标、执行缺失截断与漂移剔除。
   - v2.0 引入 `runtime_pipeline`，在本地 `outputs/runtime` 目录构建轻量级仓库，自动生成 `trajectory_points.csv`、`analysis_summary.json` 等缓存；同时保留写入 PostGIS 的接口，便于真实警务系统落库。

2. **风险识别**
   - `libpysal + esda` 实现全局/局部 Moran’s I，揭示“高-高/高-低/低-高/低-低”四类集聚模式，定位商圈、大学城、居住区等典型热点。
   - Getis-Ord Gi* 与 Mann-Kendall 趋势检验联动，识别振荡、新增、逐渐减少热点，输出 Z 值、时间片、轨迹数等指标，为警情分类与警力调度提供数据支撑。

3. **预警推送**
   - `hotspot_export` 导出附带 WGS-84 边界、中心坐标、风险等级、轨迹数的 CSV/GeoJSON，可直接嵌入警综平台或向基层单位发布预警清单。
   - Vue Leaflet 与 PyQt6 QtWebEngine 地图联动高德底图实现热点高亮、时间筛选、联动导出。

4. **应对建议**
   - 依据论文 4.1 “振荡/逐渐减少/新增热点”判定标准，结合时间段、平均速度、特定人群占比自动生成巡逻、宣教、设施优化建议，实现“策略智能推送”。

5. **用户反馈**
   - 支持交警/用户上传现场照片、文字与坐标，反馈信息与热点区域绑定，形成“数据验证—策略回流—持续优化”的闭环，体现社会共治思路。

6. **PyQt6 交互式主界面**
   - 左侧操作区承载五大业务模块与状态栏，右侧结果区展示地图、指标卡片、表格、建议文本，契合“操作-反馈”一体化警务指挥需求。
   - 蓝白配色（主色 #165DFF、背景 #F5F8FF）与警务可视化风格保持一致，提升现场处置与研判会议的体验。

## 3. 技术架构

| 层级 | 方案 |
| --- | --- |
| 表现层 | Vue3 + Element Plus + Leaflet（支持高德底图）；PyQt6 + QtWebEngine（桌面端一体化指挥大屏）；Flask 首页控制台（上传/分析/导出/反馈一体化） |
| 服务层 | Flask REST API（上传、分析、预警、反馈），`ui/services.py` 提供脱离数据库的桌面端演示封装，`runtime_pipeline` 串联所有流程 |
| 算法层 | spatial_analysis（Moran、Getis-Ord Gi*、Mann-Kendall、热点多边形生成），具备 libpysal/esda/pymannkendall 与 numpy/pandas 双实现 |
| 数据层 | PostgreSQL + PostGIS（轨迹/网格/热点）、MySQL（用户、反馈），离线模式默认使用 `outputs/runtime/*.csv|json` |
| 可视化成果 | `scripts/generate_hotspot_map.py` + `outputs/risk_hotspots.html` 交互式 HTML，可直接用于警综系统或科研展示 |

## 4. 典型使用流程

1. 研究人员/交警上传共享电动车轨迹 CSV（默认 WGS-84）。
2. 平台自动清洗并写入 PostGIS，触发空间聚合，生成网格指标。
3. 调用 Moran/Gi* API 分析某时间窗的风险分布，前端地图即时呈现。
4. 针对振荡/新增/逐渐减少热点生成策略建议，并导出预警列表。
5. 一线警力在地图上查看重点区域，执行巡逻/设施优化，同时反馈现场图文。

## 6. 版本升级要点

### 2.0 升级要点（2025-11-21）

- **Runtime 数据管线**：`backend/app/services/runtime_pipeline.py` 统一承接上传→清洗→网格化→热点输出的全流程，自动生成 `outputs/runtime` 下的 CSV/GeoJSON/HTML，轻量演示无需数据库即可闭环运行。
- **API 全面可交互**：上传、分析、导出、反馈、健康检查五大类接口重构为 `/api/...` 统一风格，POST/GET 均可直接被浏览器或 curl 调用，Leaflet/PyQt6 与 HTML 结果完全同步。
- **空间统计降级机制**：Moran、Gi*、Mann-Kendall 模块在 libpysal/esda/pymannkendall 缺失时自动使用 numpy/pandas 近似算法，保证离线环境也能输出风险等级与趋势。
- **反馈兜底**：MySQL 不可达时写入 `feedback_records.json`，同时提供 GET `/api/feedback` 读取列表，便于现场核验与复盘。
- **统一高德底图体验**：folium、Vue、PyQt6 三端共用高德瓦片密钥 `a7fd9560ffd58dcc12262f8f3d834b53`，上传完成后可立刻打开 `outputs/risk_hotspots.html` 进行地图巡检。

## 7. 理论—算法—应用映射

- **理论支撑**：紧扣“数据-行为-风险-预警”四位一体框架，围绕《论文.md》中 2~4 章的模型，将数据清洗、空间统计、趋势分析、策略生成串成闭环。
- **算法亮点**：
  - KNN 权重 + Moran’s I：揭示超速点在空间上的正/负相关性，为热点划界提供统计依据。
  - Getis-Ord Gi*：区分高值聚集与低值聚集，结合 Z 值阈值输出 high/medium/low 风险等级。
  - Mann-Kendall：洞察超速事件在时间维度的单调变化趋势，辅助判断“新增/振荡/压降”。
  - Runtime 兜底：在缺失 C 扩展依赖时仍以 numpy/pandas 方式计算，确保任何环境都能复现研究结论。
- **业务落实**：
  - 通过 `/api/export` 导出的 CSV/GeoJSON 可直接被警综系统或周例会 PPT 引用。
  - PyQt6 大屏与浏览器控制台均可实时查看热点地图、导出结果、提交反馈，实现“研判—处置—回流”闭环。
